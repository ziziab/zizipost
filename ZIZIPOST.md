# ZiziPost

ZiziPost is the social media scheduler of ZIZIAB (https://ziziab.com), Kolkata.
It is a lightly rebranded build of [Postiz](https://github.com/gitroomhq/postiz-app)
(AGPL-3.0). This repository is the public source of the version running at
https://app.zizipost.com, as the AGPL requires.

Changes from Postiz v2.25.1 (branch `zizipost`):
- ZiziPost logo, favicon and page titles
- Login page text
- Own container build: `.github/workflows/zizipost-image.yml` -> `ghcr.io/<owner>/zizipost:latest`
